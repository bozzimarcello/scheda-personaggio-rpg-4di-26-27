# Scheda Personaggio RPG 4DI-26-27
Progetto per l'esercitazione di modellazione dai dati con UML

## Istruzioni

1. Usa la cartella 01-Analisi per caricare il file di testo in formato Markdown che contiene l'analisi della scheda personaggio

2. Usa la cartella 02-UML per caricare l'immagine del diagramma delle classi UML che hai elaborato. Se ne hai,  carica anche i file sorgente che ti servono per modificarla. 

3. Usa la cartella 03-Implementazione per caricare il codice della soluzione Visual Studio che contiene l'implementazione C# delle tua classi. ATTENZIONE: non comprimere con ZIP, carica tutta la soluzione originale altrimenti ti perderai il controllo delle versioni.
